    How it works

    • Inches and degrees, in the red frame (docs/field-frame.md). The same route runs from blue.
    • Click the field to add a point. Drag any point or curve handle.
    • Lines and curves in a row are one path: one next(). New path or a turn ends it.
    • The heading holds unless a segment sets facing or tangent.
    • Outlines show the robot at the start and after each step.
    • Waits and at() actions go in the program. Loading code keeps the paths only.
